Home Backup

A personal command-line tool that makes backups of selected folders from a home directory to the owner's own Google Drive.

What it does

  • Runs on the owner's own computer as a script built on the open-source backup program duplicity, usually on a schedule.
  • Backs up only the folders the owner selects inside their home directory.
  • Uploads the backups to a folder in the owner's Google Drive, restores files from them on request, and deletes old backups according to the owner's retention settings.

How it uses Google Drive

The app signs in with Google OAuth and requests a single permission: https://www.googleapis.com/auth/drive.file. With it the app can see and manage only the files and folders it has created itself. It cannot see, read, modify or delete any other files in your Google Drive.

Access to Google Drive is used only to store, list, download and delete the app's own backup files. No Google user data is sent to the developer or to any third party. Details are in the Privacy Policy.

Who it is for

Home Backup is a personal tool operated by the owner of this website for backing up their own files. It is not a hosted service: there are no accounts, no payments and no servers operated by the developer. Everything runs on the user's own computer and talks directly to Google.
